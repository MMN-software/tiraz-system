# تحلیل سایت مرجع (asiagoldman.com)

> برند پروژه: تیرازیس طب ایرانیان (Tiraz System Iranian)
> این سند مبنای طراحی سایت جدید است.

---

## ۱. نقاط قوت احتمالی سایت مرجع

- آنلاین بودن و دیده شدن در گوگل
- داشتن اطلاعات تماس
- اشاره به حوزه تجهیزات پزشکی/صنعتی
- احتمالاً نمایش برخی گواهی‌ها
- داشتن دسته‌بندی اولیه محصولات

## ۲. نقاط ضعف اصلی

### طراحی
- ظاهر قدیمی و بدون هماهنگی بصری
- فونت‌های ناخوانا و رنگ‌بندی نامناسب
- نبود فضای سفید کافی (شلوغی بصری)
- نبود سیستم طراحی منسجم

### تجربه کاربری
- مسیر طولانی برای رسیدن به محصول
- جست‌وجوی ضعیف یا نبود آن
- نبود فیلتر و مرتب‌سازی
- فرم‌های تماس بدون اعتبارسنجی
- نبود بازخورد در فرم‌ها

### موبایل
- طراحی واکنش‌گرای ناقص
- منوی موبایل غیرکاربردی
- خارج شدن کارت‌ها از عرض صفحه
- فونت ریز و ناخوانا
- نبود دکمه تماس سریع

### نمایش محصولات
- تصاویر بی‌کیفیت و بدون گالری
- نبود صفحه جزئیات کامل
- نبود مشخصات فنی ساختارمند
- نبود محصولات مرتبط
- نبود کاتالوگ PDF

### سرعت
- بارگذاری بدون lazy-load
- نبود کش و CDN
- Core Web Vitals ضعیف

### سئو
- عنوان و توضیحات تکراری
- ساختار Heading نادرست
- نبود Schema Markup
- URLهای غیرخوانا
- نبود sitemap و robots
- نبود بلاگ و مقالات

### امنیت
- احتمال نبود CSRF Token
- نبود Rate Limiting
- نبود Sanitization ورودی

### دسترس‌پذیری
- نبود alt مناسب تصاویر
- کنتراست پایین متن
- نبود label صحیح فرم‌ها

### اعتمادسازی
- نبود نظرات مشتریان و نمونه‌کار
- نبود صفحه درباره ما و مجوزهای قوی
- نبود اطلاعات شفاف از سابقه شرکت

### محتوا
- متن‌های تبلیغاتی و بی‌ارزش
- نبود مقالات تخصصی
- نبود اخبار
- نبود FAQ

## ۳. مشکلات مسیر دسترسی به محصولات

- مسیر خانه ← دسته ← محصول ← جزئیات طولانی است
- نبود Breadcrumb
- نبود جست‌وجوی مستقیم از هدر

## ۴. امکاناتی که باید بهتر شوند

- طراحی مدرن با سیستم طراحی مستقل
- جست‌وجوی لحظه‌ای با پیشنهاد
- فیلتر ترکیبی
- مرتب‌سازی چندگانه
- صفحه محصول با گالری و مشخصات و کاتالوگ
- فرم چندمرحله‌ای با validation
- دکمه تماس سریع در موبایل
- مقالات و اخبار
- صفحات کاربر
- پنل مدیریت

## ۵. چک‌لیست تأیید شما

- [ ] طراحی سایت قدیمی است
- [ ] در موبایل درست نمایش داده نمی‌شود
- [ ] جست‌وجو ضعیف یا ندارد
- [ ] فیلتر محصولات ندارد
- [ ] صفحه جزئیات محصول ضعیف است
- [ ] بلاگ/مقالات ندارد
- [ ] فرم تماس بدون اعتبارسنجی است
- [ ] سرعت بارگذاری پایین است
- [ ] دکمه تماس سریع در موبایل ندارد
- [ ] Breadcrumb ندارد
